1. SQL code that creates the table called Student:

CREATE TABLE Student (
    STU_NUM CHAR(6) PRIMARY KEY,
    STU_SNAME VARCHAR(15),
    STU_FNAME VARCHAR(15),
    STU_INITAIL CHAR(1),
    STU_STARTDATE DATE,
    COURSE_CODE CHAR(3),
    PROJ_NUM INT(2)
);

3. SQL code that returns all records which have a COURSE_CODE of 305:

SELECT * 
FROM Student
WHERE COURSE_CODE = '305';

4. SQL code that changes the course codes to 304 for the person whose student number is 07:

UPDATE Student
SET COURSE_CODE = '304'
WHERE STU_NUM = '07';

5. SQL code that deletes the row of the person named Jamie Lannister:

DELETE FROM Student
WHERE STU_FNAME = 'Jamie'
  AND STU_SNAME = 'Lannister'
  AND STU_STARTDATE = '2012-09-05'
  AND COURSE_CODE = '101'
  AND PROJ_NUM = 2;

6. SQL code that changes PROJ_NUM to 14 for all those students that started 
before 1 January 2016 and whose course code is at least 207:

UPDATE Student 
SET PROJ_NUM = 14 
WHERE STU_STARTDATE < '2016-01-01'
